# My Personal Website

This is a static personal website starter built as an easy-to-edit first version.

You can view the website from this link - https://imtiazither.github.io/

Files and its structures:

- `index.html` - page structure and placeholder content
- `styles.css` - layout, motion, glass styling, and responsive behavior
- `script.js` - scroll line progress, reveal animations, nav highlighting, and mobile menu
- `assets/` - optimized website images, CV PDF, and selected linked paper PDFs

How to use:

1. Open `index.html` in a browser.
2. Replace the sample text with your own story.
3. Replace assets only when they are linked from the page.
4. Avoid uploading large archive-only files; GitHub browser uploads reject files over 25 MB.
