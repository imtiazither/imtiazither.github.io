Featured Project

EduWork DataBridge

The project asks a deceptively simple question: who finished the training, passed the assessment, and received the credential? The answer crosses HR, LMS, assessment, and credential records, so the system makes each source check, exception, identity review, and evidence trail visible before anyone treats the result as fact.

  • Released as an open-source Apache License 2.0 reference framework with a public programming interface, synthetic demonstration datasets, documentation, tests, and release verification.
  • Tracks a five-stop review flow: case overview, source checks, exceptions, identity review, and evidence trail.
  • Supports safe ingestion and validation across HR, learning-management, assessment, and credential systems with transparent identity review boundaries.
  • Preserves masked, lineage-aware exports so reviewers can understand where a reported answer came from before approving use.
